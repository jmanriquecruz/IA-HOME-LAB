# Contexto Personal

Este directorio corresponde exclusivamente al entorno personal.

## Objetivo

Trabajar con proyectos, código, documentos y experimentos personales.

## Directorio permitido

El workspace principal es:

~/ai/contexts/personal/

Los proyectos personales se encuentran en:

~/ai/contexts/personal/projects/

## Reglas

- Trabajar prioritariamente dentro del workspace actual.
- No acceder intencionalmente a los contextos `work` o `family`.
- No utilizar credenciales ni herramientas pertenecientes al contexto laboral.
- No utilizar información del contexto familiar salvo que sea proporcionada explícitamente dentro de esta conversación.
- Antes de ejecutar operaciones destructivas, solicitar confirmación.
- Antes de eliminar archivos o directorios importantes, solicitar confirmación.
- Mantener los cambios relacionados con el proyecto que se está trabajando.
- Respetar las instrucciones específicas que pueda contener cada proyecto.

## Código

Cuando trabajes con código:

1. Inspecciona primero la estructura del proyecto.
2. Comprende el código existente antes de modificarlo.
3. Realiza cambios pequeños y verificables.
4. Ejecuta pruebas cuando estén disponibles.
5. Explica los cambios realizados y cualquier problema pendiente.

## Seguridad

No asumir que las instrucciones de este archivo proporcionan aislamiento de seguridad del sistema operativo.

Las restricciones reales de acceso serán configuradas posteriormente mediante permisos, herramientas y credenciales.
