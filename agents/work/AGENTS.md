# Contexto Work

Este directorio corresponde exclusivamente al entorno laboral.

## Objetivo

Trabajar con proyectos, código y herramientas relacionadas con el trabajo.

## Directorio permitido

El workspace principal es:

~/ai/contexts/work/

Los proyectos laborales se encuentran en:

~/ai/contexts/work/projects/

## Reglas

- Trabajar prioritariamente dentro del workspace actual.
- No acceder intencionalmente a los contextos `personal` o `family`.
- No utilizar credenciales personales.
- No mezclar información personal o familiar con información laboral.
- Tratar todo código y documentación laboral como información potencialmente confidencial.
- No copiar información laboral hacia espacios personales.
- No enviar información laboral a servicios externos no autorizados.

## Operaciones sobre código

Cuando trabajes con código:

1. Inspecciona primero el proyecto.
2. Comprende el cambio solicitado antes de modificar archivos.
3. Mantén los cambios limitados al objetivo solicitado.
4. Ejecuta las pruebas disponibles.
5. Revisa los cambios antes de considerarlos terminados.
6. Explica cualquier riesgo o incertidumbre.

## Azure DevOps

Cuando Azure DevOps sea integrado:

- Inicialmente utilizar acceso de solo lectura.
- No publicar comentarios automáticamente.
- No aprobar Pull Requests automáticamente.
- No hacer merge automáticamente.
- No crear commits ni modificar ramas remotas sin autorización explícita.
- Las operaciones que cambien información en Azure DevOps deberán requerir confirmación.

## Outlook

Cuando Outlook/Microsoft 365 sea integrado:

- Inicialmente utilizar acceso de solo lectura.
- No enviar correos automáticamente.
- No responder correos automáticamente.
- No eliminar correos.
- No modificar información del buzón sin autorización explícita.
- Los borradores podrán prepararse para revisión, pero el envío requerirá confirmación.

## Seguridad

No asumir que este archivo proporciona aislamiento real del sistema operativo.

La separación efectiva deberá implementarse posteriormente mediante permisos, credenciales, herramientas y configuración de OpenCode.

Toda información laboral debe tratarse como confidencial.
